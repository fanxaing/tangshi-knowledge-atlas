数据说明与方法论

全唐诗 · 知识图谱 — 以完整语料驱动的唐代诗歌关联网络

数据来源

诗作全文来自 GitHub 开源项目 chinese-poetry/chinese-poetry（公共领域 / Unlicense）， 即《全唐诗》结构化整理本，共 — 首（去重后），作者 — 人。 原始文本为繁体，构建时统一繁转简。

图谱如何生成

  • 诗人筛选：以存诗量为主要依据，结合文学史地位，选入 — 位名家；节点大小 = 该诗人在语料中的真实存诗量。
  • 题材：对每位诗人的全部作品做题目与正文的多标签关键词判定（送别、边塞、田园、山水、咏史怀古等 19 类），统计命中篇数作为边权重。
  • 意象：以正则词表在诗作正文中匹配（月、酒、柳、雁、孤、空等），同一首诗对同一意象只计一次，避免单篇长诗放大权重；意象之间的连线为同诗共现频次。
  • 地名：以唐代地名及其别称词表匹配（长安、扬州、玉门关、洞庭、庐山等 43 处），并标注今日所属区域。
  • 典故：以典故词表匹配，每则典故附出处与释义（桃源、易水、赤壁、望帝春心、莼鲈之思等 46 则）。
  • 并称与影响：李杜、元白、韩孟、小李杜等并称关系，以及师承、奖掖、唱和、影响等人际边，均据文学史共识人工标注。
  • 名篇：人工选目约 — 首名篇，正文全部由语料库自动回填校验，不含任何手工录入或臆造的诗句。

如何阅读

「视图」用于切换关注维度，避免一次性呈现全部关系造成视觉过载：全景适合观察整体结构，单维度视图适合追问某个题材／意象／地名的分布。左侧统计条与图例均可点击，右侧详情卡支持逐层跳转。搜索框支持键盘 / 快速聚焦。

技术实现

纯静态单页：原生 JavaScript + Cytoscape.js 力导向布局， 无框架、无构建步骤。数据以脚本形式注入，因此既能由任意 HTTP 服务器托管，也能直接双击 index.html 离线浏览。

局限

题材与意象均为关键词规则判定，存在误判与漏判；典故用词的判定以词表为准，未做语境消歧。图谱呈现的是「语料中的统计事实」，而不是对诗歌优劣的评价。欢迎指出疏漏。
